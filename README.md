## How to Use

1. Add your exercise files to the matching topic folder.
2. Keep guided/classroom exercises in `gcr-codebase/`.
3. Keep independent practice in `practice-codebase/`.
4. Update this README as you add more topics or projects.

## Topics

- **HTML:** page structure, semantic elements, tables, lists, forms, and responsive HTML.
- **CSS:** selectors, box model, layout, animation, responsive design, and common UI patterns.
- **Bootstrap:** fundamentals, grid layout, components, themes, and alerts.
