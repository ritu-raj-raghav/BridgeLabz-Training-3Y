Assignment 7 — Question 10

Interactive Navigation Bar Showcase

This navbar features 5 distinct links, smooth transitions styled via transition: all 0.3s ease;, an emphasized active link indicator, and a responsive media query that seamlessly converts the horizontal bar into a stacked vertical menu on viewports below 700px.

⇄ Resize your browser window below 700px to see the navigation links stack vertically!

Technical Implementation Highlights

Smooth Transitions

Links utilize transition: all 0.3s ease; for graceful background, color, border, and shadow interpolations on :hover.

Active State Highlight

The active link is highlighted with an illuminated accent background and a distinct bottom border to ground user spatial orientation.

Breakpoints < 700px

Under @media (max-width: 700px), the flex container flips from row to column, cleanly stacking links with 100% width.
