Demonstrating Dimensions, Units & Overflow

The container below vertically and horizontally centers three distinct boxes using Flexbox. Each box utilizes different CSS units (px, %, vh, em), and demonstrates min-height, max-width, and overflow.

Box 1: px & em

width: 260px | height: 16em

Dimensions set via fixed pixels and typographic em units.

  • width: 260px
  • height: 16em
  • max-width: 90%

Box 2: % & Overflow

width: 30% | min-height: 240px

Demonstrates overflow-y: auto. Scroll inside this box to see hidden content:

When content exceeds the explicit box height, overflow: auto provides a scrollbar, preventing content from bleeding out of the container boundary.

This box also utilizes min-height: 240px and max-width: 320px for responsive stability across varying viewports.

Box 3: vh & vw

width: 22vw | height: 32vh

Sized relative to browser viewport dimensions (vw and vh).

  • width: 22vw (max 300px)
  • height: 32vh (min 220px)
  • overflow: hidden (clipped)

Property Breakdown

Property Role in Layout Example in Demo
min-height Guarantees the element never shrinks below this threshold. min-height: 240px; on Box 2
max-width Restricts expansion beyond a threshold, preventing overflow. max-width: 320px; on Box 2 & 3
overflow Controls behavior when content overflows container bounds (visible, hidden, scroll, auto). overflow-y: auto; on Box 2
Flexbox Center Centers elements along both main and cross axes. justify-content: center; align-items: center;
