Type 1

Linear Gradient with Fixed Background (Parallax)

This section uses a multi-stop linear gradient angled at 135deg. Additionally, background-attachment: fixed; locks the gradient image to the viewport, producing an immersive parallax-like visual effect as the user scrolls.

CSS Syntax Used:

background: linear-gradient(135deg, #1a365d 0%, #2b6cb0 50%, #4299e1 100%);
background-attachment: fixed;
Angle: 135deg (Top-Left to Bottom-Right)
Attachment: fixed (Parallax scroll effect)
Stops: Navy (#1a365d) → Royal Blue → Sky Blue
Type 2

Radial Gradient Background

This section features a vibrant radial gradient emanating outward from the center in concentric rings, seamlessly transitioning through rich hues of magenta, deep indigo, and obsidian.

CSS Syntax Used:

background: radial-gradient(circle at center, #97266d 0%, #44337a 45%, #1a202c 100%);
Shape & Origin: Circular at center
Spread: Concentric radiant illumination
Stops: Magenta (#97266d) → Indigo (#44337a) → Dark Slate

Linear vs. Radial Gradients Summary

Linear Gradient

  • Transitions smoothly along a straight vector line.
  • Can be directed via angles (e.g. 45deg, 135deg) or keywords (to right, to bottom).
  • Combines with background-attachment: fixed for fixed-position background effects.

Radial Gradient

  • Transitions colors outward from a designated origin point.
  • Shapes include circle and ellipse.
  • Origins can be centered or positioned using keywords (e.g. at top left).
