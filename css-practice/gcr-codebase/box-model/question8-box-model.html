Box Model Layers

Every HTML element is a rectangular box made up of four layers: Margin → Border → Padding → Content.

MARGIN
(outer space — transparent)
BORDER
(visible edge)
PADDING
(inner space)
CONTENT
(text / images)

Margin

Clears an area outside the border. Completely transparent. Controls space between elements.

margin: 30px;

Border

Goes around the padding and content. Can have style, width, and color.

border: 4px solid #333;

Padding

Clears an area around the content inside the border. Inherits background color.

padding: 20px;

Content

The actual content — text, image, or other media. Sized by width and height.

width: 200px; height: 100px;

Default vs box-sizing: border-box

By default, width applies only to the content. With box-sizing: border-box, padding and border are included inside the declared width — making layouts much more predictable.

Default (content-box)

width: 200px

padding: 20px

border: 5px solid

Actual rendered width:
250px

200 + 20×2 + 5×2 = 250px

border-box

width: 200px

padding: 20px

border: 5px solid

Actual rendered width:
200px

Padding + border fit inside 200px

Outline is NOT Part of the Box Model

Unlike borders, outline does not take up space and does not affect layout. It is drawn outside the border edge.

Border

Takes up space

Outline

Does NOT take up space
