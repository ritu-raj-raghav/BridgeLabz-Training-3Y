Outline Property Essentials

Does Not Affect Layout

Unlike border, an outline does not take up box-model space. Focusing an input with a thick outline will never push surrounding elements or cause layout jumps.

outline-offset

The outline-offset property creates a transparent moat or gap between the border edge and the outline perimeter, dramatically enhancing visual accessibility.

Accessibility First

Never remove outline: none without supplying a high-contrast replacement. Keyboard navigators rely on clear focus indicators to orient themselves on the page.
