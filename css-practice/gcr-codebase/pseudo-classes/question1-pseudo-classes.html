Interactive Pseudo-Classes (:hover, :focus, :active, :nth-child())

Pseudo-classes target elements based on their state or structural position. Below are interactive links, buttons, and list items neatly aligned in one Flexbox row with explanatory text beside each live demonstration.

1. :hover on Links

Triggers when user points cursor over the link. Notice the background fill, color inversion, and border lift.

Hover Over Me
a:hover { background: #3182ce; color: #fff; }

2. :focus on Interactive Input

Triggers when the element receives focus via mouse click or keyboard Tab. Notice the illuminated ring.

input:focus { border-color: #38a169; outline: 3px solid #9ae6b4; }

3. :active on Buttons

Activates at the exact instant the element is being clicked/pressed down by the user.

button:active { transform: scale(0.96); background: #9b2c2c; }

4. :nth-child() on Lists

Selects child elements according to formulaic index patterns (e.g. even or odd).

  • Item 1 (Odd: #ebf8ff)
  • Item 2 (Even: #e6fffa)
  • Item 3 (Odd: #ebf8ff)
  • Item 4 (Even: #e6fffa)
li:nth-child(even) { background: #e6fffa; }

Pseudo-Class State Progression

Default State

Resting baseline appearance when no user interaction or condition is met.

:hover State

Cursor enters bounding box. Provides predictive feedback that element is interactive.

:focus State

Target element is ready for keyboard inputs and screen reader navigation.

:active State

Physical mouse down or touch press down. Confirms user command execution.
