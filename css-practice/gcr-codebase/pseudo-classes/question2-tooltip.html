Pure CSS Tooltip Architecture

Parent: position: relative;

Establishes a local coordinate containment block so child tooltips calculate absolute offsets relative to their trigger icon.

Child: position: absolute;

Placed above the element using bottom: 125%; left: 50%; transform: translateX(-50%); to ensure perfect horizontal centering.

Smooth Opacity Fade

Employs opacity: 0; and transition: 0.3s ease-in-out;. On :hover, opacity transitions to 1 without layout shifts.
