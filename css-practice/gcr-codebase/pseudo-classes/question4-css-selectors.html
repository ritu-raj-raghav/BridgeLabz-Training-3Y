1. Basic Selectors (Element, Class, and ID)

CSS basic selectors match elements according to tag name, reusable classes, or unique identifiers.

Standard paragraph element styled uniformly via the p element selector.

.highlight-box (Class Selector)

Classes can be reused across any number of HTML elements to enforce design consistency.

#featured-notice (ID Selector)

ID selectors possess higher specificity and target a strictly unique element in the DOM.

2. Attribute Selectors ([target="_blank"], [download])

Attribute selectors target elements matching attribute existence or explicit values.

  • External MDN Documentation (target="_blank" icon)
  • Internal Navigation Link (no target attribute)
  • Download Codebase Assets ([download] attribute)

3. Combinator Relationships

Combinators articulate precise relational paths between DOM nodes.

Lead Heading Reference

Adjacent Sibling: Immediately follows the h3 heading (h3 + p).

General Sibling: Shares the parent and appears after heading (h3 ~ p).

Direct Child: .child-subgroup > span
Deeply Nested Descendant: .combinator-family-box em
