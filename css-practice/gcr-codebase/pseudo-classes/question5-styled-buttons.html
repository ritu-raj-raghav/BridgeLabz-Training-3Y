Interactive Button Showcase

Below is a cohesive button collection featuring Primary, Secondary, Outline, and Disabled variants. Experience dynamic :hover, :active, :focus, and :disabled states aligned with consistent spacing using Flexbox.

Button States & Design Token Specifications

:hover Interaction

Elevates the button via transform: translateY(-2px) and intensifies drop shadow.

:active Interaction

Simulates physical depression using transform: translateY(1px) scale(0.98).

:focus State

Emits an accessible focus ring with outline-offset: 3px for keyboard navigation.

:disabled State

Neutralizes user interaction via cursor: not-allowed, reduced opacity, and grayscale.
