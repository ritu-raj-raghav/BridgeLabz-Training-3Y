Keyframe Animations with Advanced Timing Control

Below are three distinct CSS animated elements demonstrating @keyframes, animation-delay, animation-iteration-count, animation-direction, and ease-in-out timing. All three stages are aligned and centered vertically and horizontally using Flexbox.

1. Moving Pulse Box

@keyframes slidePulse

Delay: 0.3s
Iteration: infinite
Direction: alternate
Timing: ease-in-out (2.4s)

2. Bouncing Ball

@keyframes bounceBall

Delay: 0s
Iteration: infinite
Direction: alternate
Timing: ease-in-out (1.1s)

3. Chroma Shifting Text

INNOVATION
@keyframes chromaShift

Delay: 0.6s
Iteration: infinite
Direction: alternate-reverse
Timing: ease-in-out (3.2s)

Animation Sub-Properties Explained

animation-delay

Offsets the onset of the animation cycle. Staggering delays across multiple components creates pleasing choreographed visual rhythm.

animation-iteration-count

Specifies how many times the sequence plays (e.g. 3, 5, or infinite).

animation-direction

Controls cycle trajectories: normal, reverse, alternate (reverses direction every cycle), or alternate-reverse.
