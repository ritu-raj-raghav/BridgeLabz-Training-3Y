content-box vs. border-box

Both boxes below have the exact same declared CSS properties: width: 240px, padding: 25px, and border: 6px solid. Notice how box-sizing completely alters the final rendered geometry on screen.

Default: content-box

Declared: 240px

+ 25px padding × 2

+ 6px border × 2

Actual Rendered: 302px

Width applies only to content. Padding and border expand outward, enlarging the element.

Modern: border-box

Declared: 240px

– 25px padding × 2

– 6px border × 2

Actual Rendered: 240px

Padding and border are absorbed inside the 240px boundary. Sizing is predictable.

Mathematical Formulas Compared

content-box Total Width Formula

Total Width = width + padding-left + padding-right + border-left + border-right

240px + 25px + 25px + 6px + 6px = 302px

border-box Total Width Formula

Total Width = declared width (Content absorbs remainder)

Total = 240px (Content area = 240 - 50 - 12 = 178px)
