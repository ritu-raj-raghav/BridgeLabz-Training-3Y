Responsive Multi-Breakpoint Cards

Assignment 9 — Question 3 | BridgeLabz Training

Breakpoint Grid Adaptation (4 → 2 → 1 Columns)

Four cards arranged in a row using Flexbox with equal spacing and padding. The layout adapts at key media query breakpoints: Desktop (4 columns) → Tablet ≤ 900px (2 columns) → Mobile ≤ 600px (1 column). Hover over each card to see its background color smoothly change.

Media Query Matrix

Desktop (> 900px)

4 Columns (flex: 1 1 calc(25% - 15px))

Tablet (≤ 900px)

2 Columns (flex: 1 1 calc(50% - 15px))

Mobile (≤ 600px)

1 Column (flex: 1 1 100%)
