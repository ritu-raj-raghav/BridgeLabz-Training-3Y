CSS clamp() Function

Fluid Scalable Heading Typography

The CSS clamp() function takes three parameters: a minimum bound, a preferred viewport-relative target (e.g. 4vw or 2vw), and an upper ceiling. This allows your typographic hierarchy to scale organically with window dimensions without relying on dozens of abrupt media queries.

h1 { font-size: clamp(1.5rem, 4vw, 3rem); }
p { font-size: clamp(1rem, 2vw, 1.5rem); }

Mathematical Mechanics of clamp(MIN, VAL, MAX)

1. Minimum Bound (1.5rem / 1rem)

Prevents text from ever collapsing below a legible baseline, even on compact mobile devices.

2. Preferred Scale (4vw / 2vw)

Dynamically tracks window width, allowing the type to smoothly expand during browser resizing.

3. Maximum Ceiling (3rem / 1.5rem)

Caps the text dimension to preserve editorial proportion on ultra-wide desktop monitors.
